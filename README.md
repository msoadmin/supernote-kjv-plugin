# Supernote KJV Plugin

A Scripture reference recognition and lookup plugin for Supernote.

This plugin makes it easier to work with Bible references while using a Supernote device. It recognizes handwritten Scripture references and provides quick access to the corresponding text of the King James Version (KJV).

## Features

- Recognizes handwritten Bible references
- Supports standard abbreviations such as `Jn 3:16`, `1 Pe 1:1-6`, and `2 Cor 5:17`
- Handles numbered books such as 1 & 2 Corinthians, 1 & 2 Peter, and 1, 2 & 3 John
- Corrects common handwriting/OCR errors in Scripture references
- Displays the KJV passage in a convenient popup
- Designed specifically for Supernote

## Installation


Download the .snplg file (available at link below) into the Supernote’s MyStyle folder, then choose Settings → Apps → Plugins → Choose Installation Package and select it.

## Bible Text

Scripture quotations and Bible text used by this plugin are from the King James Version.
